# Файл для проведения лекций по курсу «Использование ИИ»

Здесь живут исходники ноутбуков лекций в формате Jupytext `py:percent`.

## Как устроены материалы

- Каждая подтема лекции — отдельный ноутбук.
- Исходники: `*.py` (Jupytext `py:percent`) — канонические.
- Готовые ноутбуки: `*.ipynb` — артефакт для запуска.
- Конвертация: `jupytext --to ipynb <name>.py`
- Выполнение: `jupyter nbconvert --to notebook --execute <name>.ipynb`
