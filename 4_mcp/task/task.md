## 7. Работа C (со звёздочкой): MCP над курсами ЦБ РФ

**Задание:** завернуть в MCP настоящий публичный API курсов валют ЦБ РФ — скачать XML по HTTP, распарсить и отдавать данные через три инструмента. Работа факультативная, обязательную часть не заменяет.

### Данные

Источник — зеркало курсов ЦБ в UTF-8:

```text
https://www.cbr-xml-daily.ru/daily_utf8.xml
```

Бесплатно, без ключа и регистрации. (На том же зеркале есть JSON-версия `daily_json.js`; для этой работы используйте именно XML — цель раздела — навык парсинга.) Официальный XML ЦБ (`https://www.cbr.ru/scripts/XML_daily.asp`) отдаёт кодировку cp1251; зеркало даёт тот же формат в UTF-8.

Структура: корень `<ValCurs Date="20.10.2026">`, внутри 54 элемента `<Valute ID="...">` с полями `NumCode`, `CharCode`, `Nominal`, `Name`, `Value`, `VunitRate`. Пример (проверено 20.10.2026):

| CharCode | Nominal | Name | Value |
|---|---|---|---|
| AUD | 1 | Австралийский доллар | 57,7882 |
| USD | 1 | Доллар США | 82,8504 |
| JPY | 100 | Иен | 52,4668 |

Правила:

1. `Value` — строка с **запятой** как разделителем («57,7882»); при переводе в число заменяйте запятую на точку.
2. `Nominal` — не всегда 1 (у JPY — 100): курс задан **за указанный номинал**, а не за единицу.
3. `RUB` в списке нет — это базовая валюта. В `convert` её надо обрабатывать как курс 1 (либо явно запрещать; выбранное решение описать).
4. Дата набора — атрибут корня `Date` (формат `20.10.2026`).

### Реализуйте три tools

Новый файл `student_external.py`, сервер `cbr-rates`, результаты — словари для JSON.

| Tool | Аргументы | Результат |
|---|---|---|
| `list_rates` | — | `{"date": ..., "rates": [...]}`: код, номинал, имя, курс каждого `Valute` |
| `rate` | `code: str` | код, номинал, имя, курс, дата; неизвестный код — ошибка |
| `convert` | `amount: number`, `from_code: str`, `to_code: str` | `from_amount`, `from_rate`, `to_rate`, `to_amount`, `date`, где `to_amount = amount × (from_rate / from_nominal) / (to_rate / to_nominal)` |

Требования (те же, что в работах A и B):

1. HTTP только через `httpx` с таймаутом; данные не импортируются из зеркала.
2. Базовый URL из переменной окружения `CBR_XML_URL`; по умолчанию `https://www.cbr-xml-daily.ru`.
3. XML парсится стандартной библиотекой `xml.etree.ElementTree`.
4. HTTP-ошибка, недоступность сервера или не-XML ответ → понятная ошибка инструмента (`ToolError`), а не пустой список.
5. Неизвестный `CharCode` (например, `rate("XXX")`) → ошибка.
6. `convert` обязан учитывать `Nominal` (курс за номинал).
7. Бонус к работе: кешировать ответ на 15–30 минут — данные обновляются раз в день, повторные запросы не должны обращаться в сеть.

### Проверки работы C

Курсы меняются — сверяйтесь с данными на день выполнения (`client.py` покажет актуальные). Ожидания ниже — для 20.10.2026.

| Вызов | Ожидаемый результат |
|---|---|
| `list_rates()` | 54 валюты, в ответе есть дата |
| `rate("AUD")` | номинал 1, `value` 57,7882 |
| `rate("JPY")` | `nominal` **100** — курс за сотню единиц |
| `rate("XXX")` | ошибка: валюта не найдена |
| `convert(100, "USD", "RUB")` | ≈ 8285,04 RUB |
| `convert(1000, "JPY", "RUB")` | ≈ 524,67 RUB (номинал 100 учтён) |
| `convert(100, "RUB", "USD")` | ≈ 1,21 USD (RUB — базовая валюта) |
| Остановить сеть или задать неверный `CBR_XML_URL` | ошибка недоступности, не пустой список |
