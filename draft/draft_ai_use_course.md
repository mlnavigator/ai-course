# Курс — Современное использование ИИ в бизнесе и разработке ПО

Аудитория: студенты 3–4 курса ИТ-специальностей + практикующие ИТ-специалисты, входящие в тему.

## 1. Основы LLM и промпт-инжиниринг (4 ч лекций)

- Что такое LLM: токены, контекстное окно, температура, top-p
- Архитектура трансформера — концептуально (attention, positional encoding — обзорно, без глубокой математики)
- Плотные LLM / MoE (Mixture-of-Experts)
- Базовые техники промптинга
  - Zero-shot, few-shot, chain-of-thought
  - Role-based prompting, инструкция как контракт
  - Структурированный вывод: JSON mode, tool calling
- Контекст-инжиниринг
  - Управление контекстным окном: что помещается, что обрезается, стратегии сжатия
  - Системные промпты vs пользовательские
  - Сбор релевантного контекста для задачи
  - Шаблонизация промптов (prompt templates, Jinja2 для промптов)
- Практика: доступ через OpenAI-like API, OpenRouter

## 2. Эмбеддинги, векторные БД и RAG (2 ч лекций)

- Что такое эмбеддинги: размерности, косинусное сходство
- Векторные БД: практический обзор (Qdrant, Chroma, pgvector, Pinecone)
- Chunking стратегия: размер, перекрытия, метаданные
- RAG — Retrieval-Augmented Generation
  - Базовый пайплайн: index → retrieve → generate
  - Hybrid search (BM25 + векторы)
  - Reranking, кросс-энкодеры
  - Метрики качества поиска (recall@k, MRR)

## 3. Работа с изображениями (2 ч лекций)

- Векторизация изображений: ResNet, CLIP — эмбеддинги изображений
- VLM — модели анализа изображений (в связке с мультимодальным RAG)
- Генерация изображений: diffusion-модели, Stable Diffusion, Kandinskiy
- Image generation web UI — локальный запуск

## 5. Мультиагентные системы (2 ч лекций)

- A2A-протокол (Agent-to-Agent) — коммуникация между агентами
- Делегирование задач между агентами
- Дебаты — несколько агентов обсуждают решение с разных позиций
- Циклы актор-критик (actor-critic): один агент генерирует, другой критикует
- Циклы Ральфа — итеративная рефлексия и улучшение результата
- Human-in-the-loop: где нужен контроль человека
- LangGraph и конечные автоматы — оркестрация агентов как state machine

## 6. Разработка с использованием ИИ (6 ч лекций)

### 6.1 Spec-driven development

- Спецификация как договор между человеком и ИИ-агентом
- Архитектура проекта — как описать, чтобы агент работал эффективнее
- Итерационная разработка и управление сложностью
- Ревью и контроль кода с ИИ: что делегировать, что проверять вручную

### 6.2 Классические принципы — через призму ИИ

- TDD — почему тесты незаменимы при ИИ-генерации: агент пишет быстро, но без тестов регрессии неизбежны
- DDD — доменная модель как граница для агента: что он может менять, что нет
- MVC — разделение слоёв, чтобы агент вносил изменения точечно, и не делал лапшичный код
- SOLID — как принципы помогают агенту вносить изменения без поломки смежных модулей
- Clean Code — концепции зон ответственности: агент должен понимать границы ответственности и структурировать свое вмешательство

### 6.3 Web-разработка с использованием ИИ

- Написание REST API сервиса
- Вёрстка с использованием ИИ — вёрстка по макету
- Написание веб-приложения по MVC
