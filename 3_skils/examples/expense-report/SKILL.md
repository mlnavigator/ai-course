# Отчёт по расходам за месяц

## Когда использовать

- Задача «посчитай мои расходы за месяц», «разбери траты по категориям»,
  «сделай отчёт по таблице расходов».
- Вход — CSV с колонками `date,category,amount,note`.

## Вход

Путь к существующему CSV: UTF-8, разделитель — запятая, первая строка —
заголовок. Обязательные колонки: `date`, `category`, `amount`, `note`
(порядок не важен). Формат:

- `date` — `YYYY-MM-DD`;
- `category` — непустая строка без запятых;
- `amount` — неотрицательное число, разделитель дробной части — точка или
  запятая, пробелы и неразрывные пробелы допускаются;
- `note` — любое текстовое описание.

Если файл не указан или недоступен — запроси его.

## Порядок работы

1. Уточни путь к CSV и (необязательно) символ валюты.
2. Запусти скрипт относительно корня пакета:

   ```bash
   python3 scripts/aggregate_expenses.py data/expenses.csv
   ```

   Для валюты добавь `--currency ₽` (значение по умолчанию — `₽`).
3. Прочитай JSON из stdout: `total`, `categories`, `by_date`, `issues`.
4. Если `ok=false`, перечисли проблемы из `issues` и спроси, как их
   обработать; не додумывай недостающие суммы.
5. Если `ok=true`, оформи отчёт по шаблону `assets/report-template.md`,
   подставив числа из JSON.

## Правила

- Скрипт не перезаписывает входной файл и не исправляет данные в нём.
- Не заменяй пропущенные суммы нулями и не вычёркивай строки: строки с
  ошибками перечисляются в `issues` и исключаются из сумм до выяснения.
- Денежные итоги округляются до копеек по правилу `ROUND_HALF_UP`.
- Слово «расходы» в отчёте означает «суммы по прошедшим проверку строкам»;
  не смешивай с реальным балансом счёта.
- Не выдумывай результат запуска. Если запуск недоступен — скажи об этом.

## Выход

Markdown-отчёт по шаблону `assets/report-template.md`:
- период и число обработанных строк;
- итоговая сумма и число исключённых строк с причинами;
- сводка по категориям (сумма и количество операций), отсортированная
  по убыванию суммы;
- ограничения.

## Проверка результата

- Числа в отчёте совпадают с JSON скрипта.
- `issues` пуст или каждая проблема упомянута в отчёте.
- Сумма по категориям равна `total`.
- Исходный CSV не изменился.
