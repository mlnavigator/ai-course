# Шаблон опроса для самопроверки

Заполните по одному разделу на группу вопросов. Каждый вопрос обязан
опираться на факт из текста лекции; номер раздела указывайте в `topic`.

## Содержание опроса

**Тема 1: {раздел лекции}**

1. {Вопрос с вариантами}

   - {вариант 1}
   - {вариант 2}
   - {вариант 3}

   Правильный ответ: {номер варианта} ({цитата или факт из текста})

2. {Открытый вопрос}

   Эталонный ответ: {краткая формулировка из текста}

**Тема 2: {раздел лекции}**

3. ...

## Требования к вопросам

- Вопросы с вариантами: 3–5 вариантов, ровно один правильный.
- Нумерация вариантов в файле опроса начинается с 0 (`answer_index`).
- Открытые вопросы формулируются так, чтобы эталон помещался в 1–2
  предложения из текста.
- Избегайте вариантов «все перечисленные» и «ни один из перечисленных»,
  а также отрицательных формулировок «что НЕ верно», если без них можно
  обойтись.

## Проверка перед отправкой

- Каждый вопрос имеет `id` вида `Q1…Qn`, `topic`, `text` и эталон.
- `python3 scripts/check_answers.py --validate questions.json` — `ok=true`.
- Каждый факт из вопроса можно найти в тексте лекции.
