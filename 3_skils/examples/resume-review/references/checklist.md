# Чек-лист ревью резюме

Коды `K-01…K-10` обязательны для разбора в отзыве. Для каждого —
статус `ок` / `замечание` / `нет данных` и пояснение.

- [ ] K-01 Контактные данные и ссылки (почта, телефон, город, профили)
- [ ] K-02 Структура и читаемость (разделы, порядок, длина)
- [ ] K-03 Формулировки и опечатки (грамматика, термины)
- [ ] K-04 Опыт работы: факты и результат (не списки обязанностей)
- [ ] K-05 Ключевые навыки и инструменты (соответствие заявленному)
- [ ] K-06 Образование и курсы (релевантность)
- [ ] K-07 Соответствие вакансии (если вакансия дана)
- [ ] K-08 Пробелы и пробелы-вопросы (что требует уточнения)
- [ ] K-09 Измеримые достижения (цифры, метрики)
- [ ] K-10 Безопасность данных (лишние личные данные, ссылки)
